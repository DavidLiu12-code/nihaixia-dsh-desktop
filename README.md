# 倪海厦自学中医工作台

一个 DSH Desktop 工作台：跟着资料一讲一讲往下学，随手记笔记和疑问，想查方剂、穴位、症状或条文时直接搜。

## 它做什么

- **学习主线**：按资料文件夹里的目录和标题自动排出模块与章节，显示每份资料读到第几节。
- **章节页**：正文、`标记为已读懂`、`我的笔记` / `没弄懂的疑问`，笔记自动保存。
- **速查**：顶部搜索框按关键词检索全部资料，点结果直接跳到对应章节。
- **问 AI**：只在你看某一节时点「问 AI」，才为你打开一个和本节相关的对话；不点就一直看内容，不会自动发消息。

## 资料放在哪里

工作台**不打包任何教材**。它读你自己放在本机的资料文件夹：

1. 把讲义资料（`.md` 文件，按文件夹组织）放进一个目录，例如 `D:\dsh工作台\倪海厦\倪海厦资料`。
2. 第一次进入工作台时点「选择资料文件夹」，选中这个目录；之后还能继续添加别的资料夹。
3. 目录结构会被当作模块分组（例如 `modules/`、`cases/`、`references/`），每份文件是一讲，文件里的 `## 二级标题` 是一节。

工作台不会在你的目录里创建、移动或删除任何资料文件。

## 数据存在哪里

- 学习进度、笔记、疑问、已选资料夹：DSH 数据目录下的 `nihaixia-workbench/state.json`。
- 卸载工作台不会删除这个文件，重新安装后进度仍在。

## 本地开发

```bash
pnpm pack                       # 打包成 .tgz
node scripts/check.mjs <资料目录>   # 校验包结构，并对资料解析、检索、笔记、进度做端到端检查
node scripts/render-check.mjs      # 校验客户端注册信息与首屏渲染
```

本地安装：把 `pnpm pack` 生成的 `.tgz` 装进 DSH Desktop，重启 Harness 后从左侧「工作台」切换入口打开。
